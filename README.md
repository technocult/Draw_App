Данная программа определяет победителей в розыгрыше призов среди списка участников.
Призы и список участников передаются в виде файлов gifts.xlsx и participants.xlsx, которые должны лежать в корне рядом с jar-архивом приложения.
В результате формируется файл winners.xlsx со списком победителей и подарков.

Требования к файлам:
1. Файл gifts.xlsx должен состоять из одной "страницы" на которой заполнены три столбца (без заголовков) - наименование подарка (текст), количество подарков (целое число), стоимость (целое число). Стоимость не обязательно должна быть точной, она нужна для сортировки подарков по цене, чтобы более ценные подарки разыгрывались в первую очередь. Выставляя стоимость можно управлять очерёдностью розыгрыша призов. Если есть одинаковые подарки, отличающиеся, например, цветом, лучше записать их отдельно, с указанием цвета, при этом стоимостью можно определить порядок розыгрыша, либо указать одинаковую стоимость.
2. Файл participants.xlsx должен состоять из одной "страницы" на которой заполнен один столбец (без заголовка) - лицевой счёт участница розыгрыша (текст либо целое число).

Программа формирует log-файл.
В случае выявления несоответствия типа данных в файлах *.xlsx требуемым, программа сформирует соответствующее сообщение с log-файле.
